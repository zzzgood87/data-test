┌─────────────────────────────────────────────────────────┐
│  ⚡ 빠른 실행 (이미 설치 완료한 경우)                   │
└─────────────────────────────────────────────────────────┘

【 Windows 사용자 】
1. "실행하기.bat" 파일을 더블클릭
2. 끝! 자동으로 브라우저가 열립니다

【 Mac 사용자 】
1. "실행하기.sh" 파일을 오른쪽 클릭
2. "열기" 선택
3. 터미널이 열리면서 자동 실행됩니다


┌─────────────────────────────────────────────────────────┐
│  🔧 수동 실행 방법                                      │
└─────────────────────────────────────────────────────────┘

【 1단계 】명령 프롬프트/터미널 열기

【 2단계 】백엔드 서버 실행
   cd backend
   npm run dev

【 3단계 】새 명령 프롬프트/터미널 열기

【 4단계 】프론트엔드 실행
   cd frontend
   npm run dev

【 5단계 】브라우저에서 접속
   주소: http://localhost:3000

┌─────────────────────────────────────────────────────────┐
│  ❓ 문제가 생겼나요?                                    │
└─────────────────────────────────────────────────────────┘

【 문제 1 】"npm을 찾을 수 없습니다"
→ 해결: Node.js를 설치하세요
   https://nodejs.org/ 에서 다운로드

【 문제 2 】포트가 이미 사용중
→ 해결: 컴퓨터를 재시작하세요

【 문제 3 】지도가 안 보임
→ 해결: 브라우저 새로고침 (F5)

【 문제 4 】로그인 정보 분실
→ 해결: backend/database.sqlite 파일을 삭제하고
        서버를 재시작한 후 다시 회원가입


┌─────────────────────────────────────────────────────────┐
│  📱 모바일에서도 사용 가능!                             │
└─────────────────────────────────────────────────────────┘

같은 WiFi에 연결된 경우:
1. 컴퓨터 IP 주소 확인
2. 모바일 브라우저에서 접속
   예: http://192.168.0.10:3000
